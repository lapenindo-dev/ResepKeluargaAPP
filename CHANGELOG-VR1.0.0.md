# VR1.0.0 — UI v2.7.0 Port

Base: `resep-keluarga-v2.6.1-polish-private-sql-fix`

## Perubahan
- Tampilan semua halaman dipoles ke arah desain v2.7.0: warna warm orange/coral, background cream, card rounded, tombol besar, font lebih mudah dibaca.
- Home dibuat lebih emosional dengan hero v2.7.0 dan CTA foto/resep.
- Bottom navigation disederhanakan menjadi 5 menu: Beranda, Resep, Tambah, Jadwal, Lainnya.
- Fitur yang sebelumnya ada di nav bawah dipindah ke halaman Lainnya: Bahan & Satuan, Galeri Foto, Riwayat, Backup, Help, Privacy.
- Core v2.6.1 tetap dipertahankan: Supabase login, private photo signed URL, RLS-safe behavior, export/import, koleksi, jadwal, galeri, riwayat.

## Catatan
Ini bukan mengganti app dengan demo v2.7.0 standalone yang fiturnya lebih sedikit. Ini port UI v2.7.0 ke base v2.6.1 supaya fungsi lama tetap aman.
